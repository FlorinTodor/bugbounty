# HTTP request smuggling

> Esqueleto. Complétalo **con tus palabras** al hacer los labs. Estructura completa en
> `_plantillas/Plantilla - Vulnerabilidad`.

## Qué es
Desincronización entre front-end y back-end sobre dónde acaba una petición (CL.TE / TE.CL / TE.TE, y las variantes HTTP/2). Permite envenenar peticiones de otros usuarios, saltarse controles y capturar credenciales. Técnica avanzada; PortSwigger (que la popularizó) tiene el mejor material del mundo.
