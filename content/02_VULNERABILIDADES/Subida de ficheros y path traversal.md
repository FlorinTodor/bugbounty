# Subida de ficheros y path traversal

> Esqueleto. Complétalo **con tus palabras** al hacer los labs. Estructura completa en

## Qué es
Subida de ficheros que acaba en ejecución (webshell), o path traversal para leer/escribir fuera del directorio previsto. Técnicas: doble extensión, content-type falso, SVG con XSS, polyglots, path traversal en el nombre de fichero, null byte (según stack).
